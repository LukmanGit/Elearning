===========
PS Learning
===========

Modul custom untuk mengelola platform e-learning internal di Odoo 17.

Fitur (Roadmap)
===============

* Manajemen Course / Materi
* Pendaftaran Peserta
* Pre-Test dan Post-Test
* Pelacakan Progress
* Sertifikat & Reports

Instalasi
=========

1. Salin folder ``pslearning`` ke direktori ``addons`` Odoo.
2. Restart server Odoo dan update Apps List.
3. Cari "PS Learning" lalu klik Install.
